MINDS-i Dashboard
=================

This repository is used for providing releases of the MINDS-i Dashboard.  Click [Releases](https://github.com/MINDS-i/Dashboard/releases) on the
right side to find the latest version for your platform.

Previous Releases
-----------------

Note that this dashboard is intended for robots that have a LIDAR.

If you are are using a on older robot that has a ping sensor, you want the old dashboard that
can be found in this repository: https://github.com/MINDS-i/Old-Dashboard
